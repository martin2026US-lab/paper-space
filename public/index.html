语言与翻译

原文语言自动识别。翻译和解读可以使用不同的语言与服务。

界面语言仅改变菜单和控件，翻译与解读语言分别设置。

翻译目标仅用于单句和整段翻译；解读与回答语言用于旁注、全文导读和问答。服务支持的语言会自动映射，未支持的目标不可选。原文及已有内容保持原样，切换设置不会自动翻译。
单句与整段翻译

翻译服务

翻译只发送你点击的句子或完整段落。旁注、全文导读与问答继续使用阅读 AI；不会自动改用其它翻译接口。

删除文献？

文献、旁注和对话将移入本机回收站，可随时恢复。不会删除电脑上的原文件。

文献回收站

恢复后会带回旁注、导读与对话。彻底移除仅删除阅读器副本，不删除电脑上的原文件。

彻底移除阅读记录？

阅读器保存的文献副本、结构校正、旁注、导读及全部会话（含已删除会话）将永久移除，无法通过回收站恢复。当前对话保存目录中的对应记录也会移除。电脑上的原始 PDF / Word 不会被删除。

对话保存位置

对话按文献保存为 JSON，包含全部会话（含可恢复会话）、问题、回复及引用原文；不含 API 密钥或原文件。

选择目录后，在其中建立 PaperSpace-Chats 文件夹。已有对话会复制过去；同一文献的记录以当前阅读器为准。旧目录保留，之后自动保存到新目录。文献库和密钥的位置不变。
